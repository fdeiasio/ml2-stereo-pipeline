# data/

The pipeline needs a small number of files that are the *result* of calibration, not the
input to it. Those are committed so that a fresh clone can run the server without owning a
Magic Leap 2 and a checkerboard.

## Committed

| File | What it is |
| --- | --- |
| `calibration.json` | Mono intrinsics and distortion coefficients. One calibration shared by all three world cameras. |
| `stereo_calibration_left_center_pair.json` | Stereo extrinsics for the left/center pair, plus `Q` for 3D reprojection. |
| `stereo_calibration_center_right_pair.json` | Same for the center/right pair. |
| `stereo_rectification_maps_left_center_pair.npz` | Precomputed `cv2.remap` maps for the left/center pair. |
| `stereo_rectification_maps_center_right_pair.npz` | Precomputed maps for the center/right pair. |
| `model.obj` | Reference mesh tracked by ICP. |

The `.npz` files are ~14 MB each. They are the rectification maps themselves, not something
that can be derived at startup in reasonable time, so they are tracked rather than generated.

## Not committed

`calibration/`, `stereo_calibration/` and `images/` hold the raw PNG captures used as
*input* to the calibration scripts. They are large, they are only useful if you are
re-running a calibration, and they are regenerated by pointing the cameras at a
checkerboard. They are listed in `.gitignore`.

## Regenerating

```bash
python calibrate.py          # data/calibration/*.png      -> data/calibration.json
python stereo_calibrate.py   # data/stereo_calibration/*   -> data/stereo_calibration_*.json + .npz
```

Both scripts expect a 7x6 checkerboard with 25 mm squares and read their paths from
constants at the top of the file. Edit `LOADED_PREFIXES` in `stereo_calibrate.py` to switch
between the `left_`/`center_` and `center_`/`right_` pairs.
